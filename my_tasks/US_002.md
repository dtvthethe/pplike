# Registration

```http
POST /api/users
```

Example request body:

```json
{
  "user": {
    "username": "Jacob",
    "email": "jake@jake.jake",
    "password": "jakejake"
  }
}
```

No authentication required, returns a [User](./response_format/user.md)

Required fields: `email`, `username`, `password`
