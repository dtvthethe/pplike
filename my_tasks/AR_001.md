# List Articles

```http
GET /api/articles
```

Returns most recent articles globally by default, provide `tag`, `author` or `favorited` query parameter to filter results

Query Parameters:

- Filter by tag: `?tag=AngularJS`
- Filter by author: `?author=jake`
- Favorited by user: `?favorited=jake`
- Limit number of articles (default is 20): `?limit=20`
- Offset/skip number of articles (default is 0): `?offset=0`

Authentication optional, will return [multiple articles](./response_format/multiple_articles.md), ordered by most recent first
