# AI Coding Workflow

## Bối cảnh dự án

- Backend: Laravel 13, PHP 8.3 trở lên, PostgreSQL.
- Frontend: Blade, Tailwind CSS, Vite.
- Môi trường local: Docker Compose với các service `php`, `node`, `nginx`, `postgres`.
- Test: PHPUnit, cấu hình tại `phpunit.xml`, database riêng `pplike_testing`.
- Đọc `README.md` để thiết lập môi trường; ưu tiên chạy lệnh trong Docker.
